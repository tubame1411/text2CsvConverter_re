# 汎用TXT→CSV変換＆カラム並び替え（列順入替）アプリケーション

固定長テキスト、連続空白区切り、区切り文字（カンマ/タブ/セミコロン/パイプ等）、正規表現など、多様なテキストファイル形式に対応した汎用CSV変換・列順カスタマイズツールです。

## 主な機能
1. **多様なパース方式**:
   - **空白区切り (Whitespace)**: 連続するスペースやタブを自動で1つの区切りとしてパース。
   - **固定長 (Fixed-Width)**: カンマ区切りの桁幅（例: `10, 20, 15`）を指定して各列を切り出し。
   - **区切り文字 (Delimiter)**: カンマ (`,`), タブ (`\t`), パイプ (`|`), セミコロン (`;`) など指定の記号で分割。
   - **正規表現 (Regex)**: キャプチャグループ `(...)` を持つ正規表現で行データを分解。
2. **カラムの並び替え・選択・名称変更**:
   - 出力列の順番を **「▲ 上へ」「▼ 下へ」** ボタンで自由に変更。
   - 不要な列はチェックを外してCSV出力から除外可能。
   - 列名をわかりやすい名前にリネーム可能。
3. **ユーザー定義プリセット保存・読込**:
   - 設定したパース条件やカラム並び順・名称を名前を付けて保存し、いつでも再利用可能。
4. **Excel文字化け防止**:
   - 日本語のShift-JIS/CP932やUTF-8テキストを正確に処理し、Excelで開いたときに文字化けしない **UTF-8 with BOM (`utf-8-sig`)** で出力。

## インストール・セットアップ方法

本アプリケーションはポータブル（スタンドアロン）形式の実行ファイルとして動作するため、インストーラーの実行や管理者権限、レジストリ登録などは一切不要です。Python のインストールも必要ありません。

### 1. ZIPファイルの展開
配布された ZIP ファイル（`TextToCsvConverter.zip`）を右クリックし、「すべて展開」を選択して任意のフォルダ（デスクトップや `C:\Tools` など）に解凍します。

### 2. フォルダ構成
解凍後のフォルダには以下のファイルが含まれています。
- `TextToCsvConverter.exe`: アプリケーション本体
- `presets.json`: プリセット設定ファイル（ユーザーが保存したパース設定や列順がここに記録されます。exeと同じフォルダに置いてください）
- `README.md`: 本説明書

### 3. アンインストール方法
レジストリやシステム領域を一切使用しないため、解凍したフォルダごとゴミ箱に削除するだけで完全にアンインストールできます。

## 起動方法

### GUI（デスクトップ画面）で起動
`TextToCsvConverter.exe` をダブルクリックするだけで直感的な操作画面が起動します。
デスクトップ等から素早く起動したい場合は、`TextToCsvConverter.exe` を右クリックして「送る」→「デスクトップ（ショートカットを作成）」を行ってください。

### コマンドライン (CLI) で一括実行
コマンドプロンプトや PowerShell から引数を指定して実行すると、画面を開かずにバッチ変換が行えます。

#### 1. 空白区切りファイルの変換（例: カラム順を 3, 1, 2 の順に入れ替え）
```bash
TextToCsvConverter.exe input.txt -o output.csv --mode whitespace --columns 3,1,2
```

#### 2. 固定長ファイルの変換（桁幅: 10, 20, 15、先頭2行スキップ）
```bash
TextToCsvConverter.exe input.txt -o output.csv --mode fixed --widths 10,20,15 --skip 2
```

#### 3. 保存済みプリセットを適用して一括変換
```bash
TextToCsvConverter.exe input.txt -o output.csv --preset MyPreset
```

#### 4. ヘルプの表示
```bash
TextToCsvConverter.exe --help
```
